## Constats (Findings)

### Vérification comportementale

- **Suite automatisée** : `php artisan test` scopé aux 8 stories → **67/67 verts, 610 assertions** (deuxième exécution propre ; voir incident ci-dessous).
- **Incident transitoire, résolu** : la première exécution a échoué sur `DeleteDocumentTest::it_permanently_deletes_the_file...` ("Directory [documents/1] is not empty"). Investigation : un sous-dossier vide `storage/framework/testing/disks/local/documents/1/images/`, daté de la veille (session Epic 2), a survécu au nettoyage `Storage::fake()` en début de test. Une suppression manuelle (`rmdir`) a réussi instantanément et l'exécution suivante est passée à 6/6, puis 67/67 sur l'ensemble. **Root cause : artefact de l'environnement de test Windows (verrou transitoire probable, antivirus/indexeur), pas un défaut de `DeleteDocumentAction`** — le code appelle bien `deleteDirectory()` sur le chemin correct. Aucune action de code requise ; noté pour mémoire si ça se reproduit.
- **Portée non couverte** : pas de parcours manuel navigateur effectué dans cette session (l'app n'a pas été lancée en local) — la vérification comportementale s'appuie uniquement sur la suite automatisée. Écart de portée assumé, pas caché.

### Vue d'ensemble — duplication (aucune story seule ne le voit)

Quatre duplications distinctes de logique de mapping/formatage ont été journalisées individuellement dans `deferred-work.md`, chacune jugée "trop petite pour cette story" :

1. Formatage de date fr-FR dupliqué `Index.vue`/`Show.vue` (spec-1-2)
2. Mapping mime→format dupliqué `DocumentController::previewFormat()` / `ExtractDocumentTextJob::formatFromMimeType()` (spec-1-3)
3. Mapping type→mime dupliqué `DocumentController::TYPE_MIME_MAP` (PHP) / `TYPE_OPTIONS` (Vue, `Index.vue`), reliés seulement par un commentaire (spec-1-7)
4. Piège de focus (`trapFocus()`) réimplémenté dans `Show.vue` (nouvelle boîte de suppression) sans hériter du même défaut déjà présent dans `ImportModal.vue` (celui-ci n'exclut pas les éléments `disabled`) (spec-1-8)

**Constat d'agrégat** : chaque instance individuelle est raisonnablement mineure, mais le *motif répété quatre fois* est le signal — le code n'a aucune couche partagée pour le vocabulaire du domaine (types MIME, formats, dates). Le seuil que les développeurs eux-mêmes ont fixé ("à centraliser si un 3ᵉ point de branchement apparaît", `deferred-work.md:55`, `:107`) est déjà atteint pour le mapping mime-type. *Source : `deferred-work.md:17-19, 53-55, 105-107, 29-31`.*

### Vue d'ensemble — lacune de vérification (le motif le plus répété de l'epic)

5 des 25 constats différés portent sur la même cause : **aucun outillage de test JS dans le dépôt** (pas de Vitest/Jest, aucun script `test` front dans `package.json`). Composants concernés : `DocumentTypeBadge.vue` (spec-1-2), `CategoryPicker.vue` (spec-1-5), le raccourci clavier `/` + debounce de `Index.vue` (spec-1-6), la logique de filtrage de `Index.vue` (spec-1-7), le piège de focus de la boîte de suppression (spec-1-8). *Source : `deferred-work.md:14-15, 70-71, 74-75, 94-95, 26-27`.*

1. **Outiller les tests JS (Vitest + `@vue/test-utils`)** — priorité la plus haute : un seul geste débloque 5 des 25 constats différés en même temps (voir "lacune de vérification" ci-dessus). *Propriétaire : prochaine session touchant le frontend. Remédiation proposée, pas appliquée.*
2. **Corriger `trapFocus()` dans `ImportModal.vue`** pour exclure les éléments `disabled` (même correctif trivial déjà appliqué à la nouvelle boîte de suppression de `Show.vue` : `button:not([disabled])`). *Propriétaire : prochaine session touchant ce fichier. Remédiation proposée, ticket mécanique et à faible risque.*
3. **Centraliser le mapping mime-type/format** (actuellement dupliqué à 3 endroits : `DocumentController::previewFormat()`, `ExtractDocumentTextJob::formatFromMimeType()`, `DocumentController::TYPE_MIME_MAP`) — le seuil de duplication que l'équipe s'était fixé est atteint. *Propriétaire : à planifier, réconciliation d'architecture proposée, décision humaine requise sur l'emplacement (config PHP partagée + génération du côté Vue, ou source unique exposée via Inertia).*
4. **Leçon de processus — Sprint Planning** : cet epic (et l'Epic 2) a été construit story par story sans jamais passer par le gate de faisabilité `bmad-sprint-planning`, laissant `sprint-status.yaml` inexistant jusqu'à sa génération rétroactive dans cette session. *Action : lancer `bmad-sprint-planning` avant de démarrer le prochain epic, pas seulement après coup.*
